## 🔧 How It Works

### Scoring Algorithm

```
Starting Score: 100 points

Penalties (removed points):
- Overdue tasks: -15 each (max -30)
- Pending tasks: -5 each (max -25)
- No activity: -5 per 10 days after 30 days

Bonuses (added points):
+ Recent activity: +10 (within 7 days)
+ High completion: +15 (>80% tasks done)
+ Fresh credentials: +5 (updated in last 30 days)

Final Score: Always between 0-100
```

### Example Scores

**Client A - Excellent (92/100)**
- 0 overdue, 2 pending, 12/15 completed
- Active 2 days ago
- 3 credentials updated recently
- → Result: Green, Excellent status

**Client B - Critical (38/100)**
- 5 overdue (-30), 8 pending (-25)
- Only 3/25 tasks completed
- No activity for 45 days
- → Result: Red, Critical status, needs attention

## 🎓 API Documentation

### Endpoint: GET /api/clients/:id/health

**Authentication**: Bearer token required

**Request**:
```bash
curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     http://localhost:3000/api/clients/1/health
```

**Response**:
```json
{
  "success": true,
  "data": {
    "clientId": 1,
    "clientName": "Acme Corp",
    "healthScore": 85,
    "healthStatus": "good",
    "overdueTasks": 0,
    "pendingTasks": 2,
    "completedTasks": 12,
    "totalTasks": 14,
    "completionRate": 86,
    "trend": "stable"
  }
}
```
